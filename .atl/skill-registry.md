### Convention Summary
- **Stack**: React 19 + TypeScript + Vite 6 + Zustand + Vitest + Playwright
- **Architecture**: Feature-based (feature-sliced)
- **Language**: Spanish UI, English code identifiers
- **State**: Zustand with persist middleware
- **Testing**: Vitest (unit/integration/security), Playwright (e2e)
- **Linting**: ESLint + typescript-eslint
- **Type Check**: `tsc --noEmit` (strict: false currently)
- **Commits**: Conventional Commits, Spanish descriptions
- **Branches**: `feature/{ticket}-descripcion-corta`, `fix/{ticket}-descripcion-corta`

## SDD Change Lifecycle

1. **sdd-propose** → change proposal
2. **sdd-spec** → delta specifications
3. **sdd-design** → technical design
4. **sdd-tasks** → task checklist
5. **sdd-apply** → implementation
6. **sdd-verify** → validation
7. **sdd-archive** → archive completed change
