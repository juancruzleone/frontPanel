## One-paragraph summary

PanelAdmin (super_admin) is rewired onto the **existing HomeDashboard canon** rather than a parallel design system: a new global token file (`src/shared/styles/dashboard-tokens.css`, CSS vars only), direct reuse of `src/features/home/styles/home.module.css` classes (`kpiBand`, `panel`, `attentionGrid`, `analysisGrid`, `workGrid`, `sectionHeading`, `stackedBar`, `distributionList`, `skeleton*`, `fullError`, `chartDataTable`), a **pure** aggregation module (`src/features/tenants/utils/tenantStats.ts`), a new paged fetch method on `tenantServices` (`GET /api/tenants?page&limit`, dedupe, `truncated` notice — legacy `getTenants()` untouched because `Tenants.tsx` paginates client-side), and **CSS/SVG rendering instead of Recharts** for the tenant charts. Gradient title, 16px radii, `0 4px 20px/8px 32px/12px 40px` shadows, `backdrop-filter` tooltips and `.dark`-in-a-CSS-module dead rules all go away. No Tailwind, no new dependencies, no backend schema change.

## Reality checks the design corrected from the spec

- Locales are `src/i18n/locales/*.json` (10 languages), **not** `public/locales/*/translation.json`.
- `GET /api/tenants/stats/global` **already exists** (`api/routes/route.api.tenants.js:14`) but lacks `statusDistribution`, `unknown` buckets and `evolution`; slice 1 stays client-side per spec and upgrading that endpoint is follow-up **F2**.
- Home dashboard panels carry **no** `box-shadow` at all, so "use HomeDashboard's `shadow-sm`" is implemented as `--elevation-card: none` + 1px border (floating surfaces use `--elevation-sm`).
- `<Cell fill="var(--color-…)">` in the current Recharts wrappers is unreliable as an SVG presentation attribute — an extra reason to move to the CSS/SVG canon.
